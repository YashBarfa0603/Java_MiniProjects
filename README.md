# Java Mini Projects

A collection of beginner-friendly Java mini projects built to practice core Java concepts, OOP, problem-solving, and application development.

## 🚀 Tech Stack
- Java
- OOP Concepts
- VS Code / IntelliJ IDEA

## 📂 Projects Included
- Calculator
- Student Management System
- Banking System
- Number Guessing Game
- Tic Tac Toe
- More mini projects coming soon...

## ▶️ How to Run

### Clone the Repository
```bash
git clone https://github.com/YashBarfa0603/Java_MiniProjects.git
```

### Compile and Run
```bash
javac FileName.java
java FileName
```

## 🎯 Purpose
This repository is created to improve Java programming skills and build practical projects for internships, hackathons, and learning.
